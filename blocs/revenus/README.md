# Bloc Revenus et prorata

Sections de réglages : revenus annuels, méthode du prorata, part livret perso.

## Fichiers

- `revenus.js` : `prorata(annee, methode)`, `impotsJustes(revenus)`, `METHODES` (net du mois, brut, net imposable, net − impôt juste, manuel). Pour « net du mois », `prorata()` reçoit les salaires de la clôture.

## Données

Écrit `revenus[annee]` et `reglages.methodeProrata`, `prorataManuel`, `partPerso`.
