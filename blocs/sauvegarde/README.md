# Bloc Synchronisation et sauvegardes

Bouton « Synchro » de l'en-tête, section de réglages : choix du fichier partagé, synchronisation, exports (chiffré, CSV, JSON) et fusion d'un fichier reçu.

## Fichiers

La mécanique (lecture, fusion, écriture) est dans `socle/sync.js`.

## Données

Réglage de l'appareil : `fichier`.
