# Bloc Réglages

Écran `#/reglages`. Rassemble les sections fournies par les autres blocs.

## Fichiers

- `ajouterSection(cle, titre, afficher(zone, redessiner), ordre, description)` : ajoute une section.
- `section(cle)`, `carteSection(section)` : réutilisées par le guide.

## Données

Aucune donnée propre.
