# Bloc Réévaluation des %

Section de réglages, aperçu de la proposition, alertes « % différents de 100 » et « échéances difficiles ».

## Fichiers

- `reevaluation.js` : `proposer()` (selon le temps restant, avec variation max, plancher, verrou), `normaliser()`, `faisabilite()` (couverture, date réaliste par enveloppe).

## Données

Écrit `reglages.reevaluation`, `reglages.surplus`, `reglages.seuilAlerte` et le % des enveloppes quand on applique.
